## 坑：main.cpp 顶部那个 `#ifdef _WIN32` 是一整大块
`wideToUtf8` / `windowsWallpaperPath` / `setImeRectOnChange` / `switchImeToAscii` /
`applyTouchFeedback` / `postCloseToAllInstances` **全在同一个 `#ifdef _WIN32 ... #endif`**
（414 ~ 624 行附近）。第一次图省事给 `wideToUtf8` 加 `#else` 分支，结果后面那一串
Windows 函数在 Linux 上全被编进来，报了一堆 `HIMC / WM_CLOSE / GetClassNameW 未声明`。
**要加 Linux 版本就单独 `#ifndef _WIN32` 包一段，别往这个大块里塞 `#else`。**
另外：`path_utf8::narrow/widen` 只存在于 Windows 分支，Linux 上没有，别直接调。
